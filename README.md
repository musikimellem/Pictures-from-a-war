# Pictures From A War — hjemmeside

Filen `index.html` er en komplet, responsiv one-page hjemmeside uden eksterne biblioteker.

## Gratis publicering
Den kan fx lægges på GitHub Pages:
1. Opret en gratis GitHub-konto.
2. Opret et nyt repository.
3. Upload `index.html`.
4. Aktivér GitHub Pages under repositoryets Settings → Pages.
5. Vælg branch `main` og mappen `/root`.

## Husk
- Erstat `indsæt-email-her` med den rigtige e-mailadresse.
- Tilføj egne fotos, når I har dem.
- Opdatér turnésteder og datoer, når de er fastlagt.
